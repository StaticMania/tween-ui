A hero-style illustration that **spins slowly while idle**, then **speeds up in
the scroll direction** and settles back once scrolling stops. Swap `src`, tune
`idleDuration` / `scrollDuration`, and restyle with `className`. Driven by
GSAP, and it fully respects `prefers-reduced-motion`.

## Props

| Prop             | Type     | Default | Description                                                 |
| ---------------- | -------- | ------- | ----------------------------------------------------------- |
| `src`            | `string` | —       | Image URL.                                                  |
| `alt`            | `string` | `""`    | Accessible label; empty marks the figure decorative.        |
| `idleDuration`   | `number` | `50`    | Slow continuous spin when idle (seconds per turn).          |
| `scrollDuration` | `number` | `12`    | Faster spin while the user is scrolling (seconds per turn). |

Extends native `<figure>` attributes (`className`, `style`, …).

## Accessibility

::note
Pass an empty `alt` for decorative use — the figure gets `aria-hidden`. For
meaningful images, set a descriptive `alt`. Under
`prefers-reduced-motion: reduce` the image stays static with no scroll
listeners or rotation. In a nested scroll area, wrap the component in
`[data-scroll-spin-scroller]`.
::
