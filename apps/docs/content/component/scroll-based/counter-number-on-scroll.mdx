A stats counter with two playback modes. ScrollTrigger fires it once; Number
Flow handles the digit spin. Driven by GSAP, and it fully respects
`prefers-reduced-motion`.

## Instant

Rolls up to the target as soon as the number mounts. Pass `instant` (or
`data-instant` in HTML).

::component-preview{name="counter-number-on-scroll" variant="instant"}
::

## Viewport

Holds at 0 until you scroll the number into view. In a nested scroll area,
wrap the counters in `[data-counter-scroller]`.

::component-preview{name="counter-number-on-scroll" variant="viewport" size="lg"}
::

## Props

| Prop       | Type      | Default     | Description                                       |
| ---------- | --------- | ----------- | ------------------------------------------------- |
| `value`    | `number`  | —           | Number to count to.                               |
| `duration` | `number`  | `1.8`       | Count-up length in seconds.                       |
| `delay`    | `number`  | `0`         | Wait after the trigger before counting.           |
| `instant`  | `boolean` | `false`     | Skip ScrollTrigger and play as soon as it mounts. |
| `format`   | `Format`  | grouping on | Intl-style options passed to Number Flow.         |

HTML uses `data-counter-value`, `data-counter-duration`, `data-counter-fraction-digits`, and `data-instant` on `[data-counter-trigger]`. For a nested scroll area, wrap the counters in `[data-counter-scroller]`.

## Accessibility

::note
Under `prefers-reduced-motion: reduce` the final value appears immediately,
with no digit roll. The count also runs once (`once: true`) so scrolling back
does not replay it.
::
