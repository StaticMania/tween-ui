Wrap **any inline SVG**, an icon, a logo or a whole illustration, and it
**draws itself in**. Every path, line, circle, rect and polygon **traces its
outline** one after another, longest first, then its **fill fades in** behind
the line. Outline icons draw in their own stroke and keep it; filled shapes are
traced in a thin line that fades away as they fill. Once a shape settles it is
**handed back exactly as written**. It plays when the SVG scrolls into view, or
on mount. Plain CSS transitions, no animation library.

## Usage

::tabs
:::tabs-item{label="React" icon="i-lucide-atom"}

```tsx [components/hero-mark.tsx]
import SvgDraw from '@/components/tweenui/svg-draw';

export default function HeroMark() {
  return (
    <SvgDraw className="text-teal-700">
      <svg
        viewBox="0 0 24 24"
        className="size-24"
        fill="none"
        stroke="currentColor"
        strokeWidth="1.5"
      >
        <path d="M12 3l2.6 5.6 6.1.7-4.5 4.2 1.2 6L12 16.6 6.6 19.5l1.2-6-4.5-4.2 6.1-.7z" />
      </svg>
    </SvgDraw>
  );
}
```

:::

It works with whatever SVG you put inside: an icon from a library, a logo
pasted from a design tool, or a whole illustration. Tune the pace with
`duration`, `stagger` and `ease`, and change the key to play it again.

## Props

| Prop         | Type                                   | Default          | Description                                                                 |
| ------------ | -------------------------------------- | ---------------- | --------------------------------------------------------------------------- |
| `duration`   | `number`                               | `1.6`            | Seconds each shape takes to draw.                                           |
| `delay`      | `number`                               | `0`              | Seconds before the first shape starts.                                      |
| `stagger`    | `number`                               | `0.18`           | Seconds between one shape starting and the next.                            |
| `order`      | `'longest' \| 'reverse' \| 'document'` | `'longest'`      | Which shapes go first.                                                      |
| `ease`       | `SvgDrawEase \| string`                | `'power1.out'`   | A preset or any CSS easing.                                                 |
| `width`      | `number`                               | `1.5`            | Trace width in screen px for fill-only shapes.                              |
| `color`      | `string`                               | `'currentColor'` | Trace color for fill-only shapes.                                           |
| `ownColor`   | `boolean`                              | `false`          | Trace fill-only shapes in their own fill color instead.                     |
| `trigger`    | `'view' \| 'mount'`                    | `'view'`         | Play on scrolling into view, or straight away.                              |
| `startAt`    | `number`                               | `0.85`           | With `view`: how far down the viewport the SVG's top must rise, `0` to `1`. |
| `onComplete` | `() => void`                           | —                | Called once every shape is drawn and settled.                               |

The presets are `'power1.out'`, `'power2.out'`, `'power3.out'`, `'expo.out'`,
`'in-out'` and `'linear'`. It renders a `<div>` around your SVG and extends
native `<div>` attributes (`className`, `style`, …).

## Behavior

- **Any shape, any SVG.** It finds every `path`, `line`, `polyline`,
  `polygon`, `circle`, `ellipse` and `rect`, however deeply nested in groups
  or across several SVGs. Shapes inside `defs`, `clipPath`, `mask`,
  `pattern`, `marker`, `symbol` and gradients are skipped, because they are
  never painted where they sit, and so are hidden shapes.
- **Strokes stay strokes, fills stay fills.** A stroked shape draws in its own
  stroke color and width and keeps them. A fill-only shape draws in a thin
  `color` line that fades out as its fill fades in. Colors are never swapped:
  every fill ends in its own color, gradients included.
- **The same line on any scale.** `width` is in screen pixels, so the trace
  looks the same on a 24-unit icon and on a 1000-unit logo.
- **Shapes that set `pathLength`** are measured in their own units, so the
  line still runs exactly from start to end.
- **Handed back untouched.** Once a shape has settled, its own `style`
  attribute is put back exactly as it was, so nothing lingers to fight your
  CSS. Unmounting mid-draw, a prop change or React Strict Mode's double effect
  restores the SVG too, so it is always measured as written.
- **No flash.** Where scripts run, the SVG is hidden until its first frame is
  set up, before paint. Without JavaScript it simply shows.
- **Only inline SVG.** An `<img src="logo.svg">` or a CSS background cannot be
  traced: paste the markup in, or import it as a component (SVGR). Shapes
  drawn through `<use>` and `<text>` are left as they are.

## Accessibility

::note
The drawing is decoration on top of your SVG: its markup, titles and labels
are untouched, so give the SVG an `aria-label` or `aria-hidden` as you
normally would. Under `prefers-reduced-motion: reduce` nothing animates and
the SVG shows as written straight away.
::
