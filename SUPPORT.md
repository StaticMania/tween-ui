# Support

## Questions and help

- Read the [README](README.md) and the component documentation at
  [tween-ui.vercel.app](https://tween-ui.vercel.app).
- Search [existing issues](https://github.com/StaticMania/tween-ui/issues) in case the
  question is already answered.
- Open a [GitHub issue](https://github.com/StaticMania/tween-ui/issues/new) for bugs,
  new component ideas, or usage questions that look like a product gap.

## What belongs where

| Topic                                                         | Where to go                                                         |
| ------------------------------------------------------------- | ------------------------------------------------------------------- |
| A component animates wrongly, or the CLI copies a broken file | [Open an issue](https://github.com/StaticMania/tween-ui/issues/new) |
| A new component or block idea                                 | [Open an issue](https://github.com/StaticMania/tween-ui/issues/new) |
| Something you changed after copying the source                | Yours to debug — the copied file is your code                       |
| Security vulnerability                                        | [SECURITY.md](SECURITY.md)                                          |
| Community conduct                                             | [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md)                            |
| How to contribute a component                                 | [CONTRIBUTING.md](CONTRIBUTING.md)                                  |

Please do not use GitHub issues to report security vulnerabilities.
